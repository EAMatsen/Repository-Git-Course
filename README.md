## Felles oppgave: konflikt-demo

Bruk [Common/common_task.py](Common/common_task.py) for en enkel demo av merge-konflikter.

Forslag til flyt:

1. Alle starter fra main og lager hver sin branch.
2. Alle endrer samme linje i `get_suggested_commit_title()` i [Common/common_task.py](Common/common_task.py).
3. Første person merger til main.
4. Neste person prøver å merge og får konflikt.
5. Løs konflikten sammen som del av kurset.
